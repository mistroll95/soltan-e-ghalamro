فتح قلمرو | Conquer Territory

بازی اندروید پیکسلی فتح قلمرو با HTML/CSS/JS داخل WebView.

ویژگی‌ها

· گیم‌پلی کلاسیک فتح قلمرو (کشیدن مسیر و محاصره)
· باز کردن عکس جدید با فتح هر مرحله
· تنظیم عکس به‌عنوان پس‌زمینه گوشی
· دو زبانه (فارسی/انگلیسی)
· کنترل با D-Pad، لمس و کیبورد
· لینک به مایکت برای امتیاز و نظر

تکنولوژی

Java + WebView | HTML5 Canvas | Vanilla JS | minSdk 21 / targetSdk 34

اجرا

```bash
git clone https://github.com/mistroll95/soltan-e-ghalamro.git
```

سپس عکس‌ها را با نام 1.jpg تا 10.jpg در app/src/main/assets/img/ بگذار و بیلد کن.

نحوه بازی

از قلمرو بیرون بزن، مسیر بکش، برگرد و ناحیه محاصره‌شده را تصاحب کن. از گوی‌های نارنجی دوری کن. با رسیدن به ۷۰٪ قلمرو، مرحله فتح می‌شود.
